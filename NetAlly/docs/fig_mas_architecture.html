Fig. X. NetAlly multi-agent debate architecture with MCP tool integration.
Phase 1은 Collector(🔧 도구 호출), Verifier(🔎 필터링), Synthesizer(✎ 답변 생성) 3개 에이전트로 구성된다. Collector는 tool_catalog 프롬프트를 기반으로 18개 MCP 도구(NSO 5 + Batfish 13) 중 필요한 것을 자율적으로 선택한다. Phase 2에서 Supporter(💪)-Critic(🕵) 적대적 토론을 통해 답변을 검증하며, ACCEPT(답변 확정), CONTINUE(재토론, inner loop max 2회), NEED_MORE_INFO(정보 부족, outer loop max 2회, 추가 도구 호출 트리거)의 3가지 종료 조건을 갖는다.
