As network infrastructure scales and services diversify, the complexity of network configuration and operation continues to grow.
Large language model (LLM)-based automation has emerged as a promising approach to improving operational efficiency and reducing management overhead.
However, existing benchmarks primarily assess knowledge-based question answering over standard documents or configuration generation, making it difficult to evaluate whether LLMs can accurately interpret and analyze real network configuration files.

To address this gap, we propose a unified framework integrating a benchmark, evaluation metrics, and tools, together with a multi-agent system designed to assess LLM capabilities on network configuration analysis.
For benchmark reliability and scalability, we introduce \textbf{NetConfigQA~2.0}, which automatically generates QA pairs across five cognitive difficulty levels---spanning fact extraction, path reasoning, and fault analysis---via a dual-path pipeline combining configuration files with Batfish simulation.
The dataset scales to arbitrary topology sizes by replacing only configuration and policy files.
We further introduce \textbf{Type-Aware Accuracy (TA-Acc)}, an evaluation metric that reflects the answer structure of each answer type to handle the diverse output formats in network data.

To overcome the simulation barrier faced by standalone LLMs, we present \textbf{NetAlly}, a multi-agent system that accesses network analysis tools via the Model Context Protocol (MCP).
We compare three conditions---single LLM, multi-agent system without tools, and NetAlly---and demonstrate that tool integration substantially alleviates the simulation barrier.
Experiments evaluate automation capability and accuracy on complex tasks including fault diagnosis, reachability verification, and configuration synthesis across four topologies.

These results confirm that NetAlly offers practical applicability in network management and provides a foundation for future automated network management systems.
