# Documentation Standards

**Activation:** Model Decision

---

## README Structure

1. Project Name & One-line description
2. Features
3. Installation (Prerequisites, Quick Install)
4. Quick Start (Code snippet)
5. Configuration
6. Development (Test/Format commands)
7. License & Citation (BibTeX for research)

---

## Docstring Standards

### Function/Class Docstrings

- Include: Description, Args, Returns, Raises, and a doctest-style Example.
- For classes, list all major Attributes.

---

## CHANGELOG Format

- Based on "Keep a Changelog" and Semantic Versioning.
- Sections: `Added`, `Changed`, `Fixed`, `Deprecated`.
