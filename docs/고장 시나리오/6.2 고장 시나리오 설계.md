## 1. L3VPN 질병: "잘못된 우편 배달" (RT 설정 오류)

### 🤒 증상 설명

삼성전자(VRF Red) 직원이 보낸 기밀 서류가 LG전자(VRF Blue)로 배달되거나, 아예 배달되지 않고 공중에서 사라지는 아주 심각한 보안 사고입니다.

**비유: 아파트 우편함 사고**

- 정상: 101호 우편함에는 `101호` 스티커가 붙은 편지만 넣어야 합니다.
- 고장: 관리인이 실수로 101호 우편함에 `102호` 수취 불가 스티커를 붙였습니다. 101호 편지가 와도 "어? 여기 아니네?" 하고 버려버립니다.

### 🖼️ 시각화 (Before & After)

**[정상 상태]**

```mermaid
graph LR
    P[편지: 101호 행] -->|확인: 스티커 일치!| Box[101호 우편함]
    style Box fill:#bfb,stroke:#333
```

**[고장 상태]**

```mermaid
graph LR
    P[편지: 101호 행] -->|확인: 스티커 불일치! ❌| Box[101호 우편함\n(실수로 102호 딱지 붙음)]
    P -.->|쓰레기통으로 직행| Trash[폐기]
    style Box fill:#fbb,stroke:#333
    style Trash fill:#555,stroke:#333,color:#fff
```

### 💉 주입 방법 (NSO Python Script)

```python
# NSO에게 명령: "PE1 라우터의 VRF 101호 수신 규칙을 망가뜨려라!"
def inject_fault(nso):
    device = "PE1"
    # 정상: route-target import 65000:101
    # 고장: route-target import 65000:999 (없는 번호)
    nso.config(device, "vrf definition Samsung", "no route-target import 65000:101")
    nso.config(device, "vrf definition Samsung", "route-target import 65000:999")
```

## 2. Multicast 질병: "방송 신호 끊김" (RP 주소 오류)

### 🤒 증상 설명

IPTV 시청자가 채널을 돌렸는데 화면이 **검게 나오고(Black Screen)** 아무것도 안 나오는 현상입니다. 방송국 위치를 못 찾아서 생깁니다.

**비유: 네비게이션 주소 입력 실수**

- 정상: "MBC 가자" → 네비: "여의도로 안내합니다."
- 고장: "MBC 가자" → 네비: "제주도로 안내합니다." (???)
- 결과: MBC에 영원히 도착 못 함. 방송 못 봄.

### 🖼️ 시각화 (Topology)

```mermaid
graph TD
    User[TV 시청자] -->|어디로 연결해요?| R1[우리동네 라우터]
    R1 -.->|1.1.1.1로 가! (정상)| RP_Real((진짜 방송국\n1.1.1.1))
    R1 -->|9.9.9.9로 가! (오류)| RP_Fake((가짜/없는 곳\n9.9.9.9))

    style RP_Real fill:#bfb,stroke:#333
    style RP_Fake fill:#fbb,stroke:#333
```

### 💉 주입 방법 (NSO Python Script)

```python
# NSO에게 명령: "모든 라우터의 방송국 주소록을 엉터리로 바꿔라!"
def inject_fault(nso):
    # 정상: ip pim rp-address 1.1.1.1
    # 고장: ip pim rp-address 9.9.9.9
    for router in all_routers:
        nso.config(router, "ip pim rp-address 9.9.9.9")
```

## 3. Backbone 질병: "네비게이션 고장" (Cost 불일치)

### 🤒 증상 설명

서울에서 부산 갈 때는 4시간 걸리는데, 부산에서 서울 올 때는 10시간 걸리는 기이한 현상 비대칭 경로(Asymmetric Routing)가 발생합니다.

**비유: 이상한 톨게이트 요금**

- 서울 → 부산: 톨게이트비 1만원 (정상)
- 부산 → 서울: 톨게이트비 **100만원** (오류)
- 결과: 부산에서 올 때는 고속도로가 너무 비싸다고 판단해서, **국도로 빙빙 돌아서** 옴.

### 🖼️ 시각화 (Topology)

```mermaid
graph LR
    Seoul((서울))
    Busan((부산))

    Seoul -->|고속도로 (Cost 10)| Busan
    Busan -->|국도 (Cost 10)| Daejeon((대전))
    Daejeon -->|국도 (Cost 10)| Seoul
    Busan -.->|고속도로 (Cost 1000??) ❌| Seoul

    style Busan fill:#fbb,stroke:#333
```

## 4. BGP 질병: "비합리적 경로 선택" (Local Pref 역전)

### 🤒 증상 설명

회사가 비싼 돈 주고 **"초고속 프리미엄 회선(KT)"**과 "저렴한 백업 회선(알뜰폰)"을 둘 다 개통했습니다. 그런데 인터넷이 **항상 느린 백업 회선으로만** 연결되는 답답한 상황입니다.

**비유: VIP 고객 대우 실수**

- 정상: VIP 고객(KT)이 오면 1순위로 모신다. (Pref 200)
- 고장: 알바생이 실수로 일반 고객(백업)을 VIP로 등록했다. (Pref 50 < Pref 100)
- 결과: 사장님이 오셔도 일반 손님 취급하고, 동네 꼬마를 VIP 석에 앉힘.

## 5. 공통 질병: "터널 높이 제한" (MTU 불일치)

### 🤒 증상 설명

인터넷 검색(작은 데이터)은 잘 되는데, **유튜브 동영상(큰 데이터)만 틀면 무한 로딩**이 걸리는 아주 짜증 나는 현상입니다.

**비유: 낮은 터널 높이**

- 소형차(Ping 패킷)는 터널을 슝슝 잘 지나갑니다.
- 대형 트럭(동영상 패킷)은 터널 입구 천장에 **'쾅!'** 하고 부딪혀서 못 지나갑니다.
- 원래 터널 높이가 4m여야 하는데, 공사 실수로 3m로 낮게 지었기 때문입니다.

### 🖼️ 시각화 (Process)

```mermaid
graph LR
    Small[소형차\n(Ping)] -->|높이 2m| Tunnel[터널\n(Limit 3m)] -->|통과!| Dest((도착))
    Big[대형트럭\n(Video)] -->|높이 4m| Tunnel
    Big -.->|💥 쾅! 💥| Crash[전송 실패]

    style Crash fill:#fbb,stroke:#333
    style Tunnel fill:#ddd,stroke:#333
```

### 💉 주입 방법 (NSO Python Script)

```python
# NSO에게 명령: "터널 입구 높이를 1500cm에서 1400cm로 낮춰버려라!"
def inject_fault(nso):
    interface = "GigabitEthernet0/0"
    # 정상: mtu 1500
    # 고장: mtu 1400
    nso.config("PE1", interface, "mtu 1400")
```
