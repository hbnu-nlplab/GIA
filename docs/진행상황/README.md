## 🚀 빠른 시작 가이드

### Phase 1 시작하기

1. **환경 구축** (1-2주)

   ```
   → 1. Pnetlab 설치
   → 2. NSO 설치
   → 3. NSO-Pnetlab 연동
   → 4. Batfish 설치
   ```

2. **데이터 확보** (1-2주)

   ```
   → Phase1_데이터셋_구축_전략.md의 "5.1 실험실 확보" 참고
   → PNETLab 포럼에서 4개 도메인 랩 다운로드
   ```

3. **데이터셋 생성** (2-3주)

   ```
   → Make_Dataset 실행
   → policies.json 도메인별 확장
   ```

4. **평가 실행** (1주)
   ```
   → Evaluation/pipeline_v2 실행
   → 결과 분석
   ```

## 📊 예상 성과물

### Phase 1 (현재)

- **데이터셋**: 950-1,300 QA 쌍
- **도메인**: 5개 (Backbone, L2VPN, L3VPN, BGP, Multicast)
- **장비 수**: 약 50대
- **프로토콜**: 15+ 종류
- **논문**: LLM의 네트워크 설정 이해력 평가

### Phase 2 (후속)

- **시나리오**: 75개 고장 유형
- **평가**: 진단 정확도 + 복구 성공률
- **핵심 기술**: NSO 기반 자동 복구
- **논문**: LLM 기반 자율 네트워크 관리
