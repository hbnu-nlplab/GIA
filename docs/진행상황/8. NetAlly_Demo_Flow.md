# NetAlly 데모 플로우 업데이트 로그

**작성일**: 2026-02-02  
**범위**: PNETLab 내부 배포 + Agent 데모 플로우

---

## 핵심 목표
- 데모 안정성 우선
- 수동 Bootstrap + 자동 Refresh/Prepare
- 에이전트와 자동화 분리

---

## 반영된 기능 요약

### 1) PNETLab 인증
- 쿠키 없이도 가능한 **자동 로그인** 추가
- 실패 시 **Settings에서 쿠키 입력** 가능

### 2) Refresh / Prepare 흐름
- Refresh 버튼 → 신규 장비만 부트스트랩
- Prepare 버튼 → Batfish 준비 상태 확인
- 결과는 Dashboard/Evidence에 고정 표시

### 3) Device Info 자동 생성
- `device_info.json`이 없으면 PNETLab API로 자동 생성
- Settings에서 OOB 인터페이스 등 오버라이드 입력 가능

### 4) 변경 감지
- NSO `check-sync` 기반 `detect_changes` / `sync_changed` 추가
- 신규/삭제는 `diff_report`로 요약

---

## 현재 제약
- PNETLab API 인증은 반드시 필요
- OOB 인터페이스 자동 매핑은 아직 없음 (수동 입력 권장)
- Batfish 스냅샷 준비는 수동 or Prepare 버튼 사용
