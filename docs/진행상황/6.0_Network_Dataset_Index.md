# 6.0 복잡한 네트워크 데이터셋 구축 - 완벽 가이드 (INDEX)

> **📖 이 가이드는?** 네트워크 지식이 전혀 없는 팀원도 프로젝트를 완벽히 이해하고 기여할 수 있도록 작성된 교육 자료입니다.

## 🎯 이 시리즈의 목적

1. **전략 이해**: 왜 단순한 L2VPN 하나가 아닌 5개 도메인이 필요한가?
2. **네트워크 기초**: Backbone, L2VPN, L3VPN, BGP, Multicast가 무엇인가?
3. **고장 시나리오**: 어떤 고장을 주입하고 검증할 것인가?
4. **실무 적용**: NSO로 어떻게 자동화할 것인가?

### 레벨 2: 네트워크 기초 (Network Fundamentals)

#### [6.2 네트워크 도메인 완벽 가이드](./6.2_Network_Domains_Guide.md)

**분량**: ~25,000자 (읽기 시간: 2-3시간)
**대상**: 네트워크를 처음 배우는 팀원 (교육용 통합본)

**내용**:

1. **Backbone 네트워크 (고속도로)**

   - OSPF, Fast Reroute, VoIP 시나리오

2. **Metro/L2VPN (전용 터널)**

   - VPWS vs VPLS, QinQ, 기업 전용선

3. **ISP/L3VPN (클라우드 아파트)**

   - VRF, Route Target, Route Reflector, AWS 격리 원리

4. **Internet/BGP (국경 검문소)**

   - AS, AS-Path, Local Preference, 멀티호밍

5. **Multicast (TV 방송국)**
   - Unicast vs Multicast, IGMP, PIM-SM, Anycast RP

- ✅ 중학생도 이해 가능한 비유
